## Work Summary

Built and ran a complete comparative TE fossil pipeline for D. melanogaster x D. pseudoobscura (~25 Mya divergence):

### Infrastructure
- **UTR inference** (`src/fossil_finder/io/gff.py`): Added `infer_utrs()` to auto-generate 3'/5'UTR features from mRNA-CDS coordinates for NCBI Gnomon annotations lacking explicit UTR features. Integrated into `parse_gff3()` with automatic detection.
- **Cross-BLAST rule** (`workflows/Snakefile`): Added `cross_blast` rule with `{query}` x `{subject}` wildcards, auto-generating all pairwise genome combinations via `CROSS_PAIRS`.
- **Chr prefix fix** (`src/fossil_finder/repeatmasker/library.py`): Fixed chromosome naming mismatch (UCSC `chr2L` vs FlyBase `2L`) in `build_te_fasta_from_repeatmasker()`.
- **Simple repeat filter** (`src/fossil_finder/repeatmasker/library.py`): Added `exclude_simple=True` parameter to filter Simple_repeat/Low_complexity/Satellite from TE databases. Reduced dpse DB from 199k to 10k sequences, eliminating 96% of uninformative BLAST hits.
- **Performance fixes** (`src/fossil_finder/analysis/repeatmasker.py`): Vectorized `find_overlaps()` (was O(N×M) nested iterrows = ~3.8B iterations) and `classify_hits()` (was iterrows+to_dict over millions of rows).
- **Removed `-parse_seqids`** from `makeblastdb` in Snakefile (fails on RM-derived FASTA headers with spaces).

## Key Decisions

- **D. pseudoobscura as comparison species**: ~25 Mya divergence is sweet spot for ancient TE fossil detection with reliable ortholog mapping
- **Symmetric RM treatment**: Both genomes use RepeatMasker-derived TE libraries (not curated FlyBase consensus) for fair comparison
- **Simple repeat exclusion**: Critical fix — Simple_repeat/Low_complexity inflated dpse hits by 26x (25.3M → 959K after filtering)
- **Standalone comparative scripts**: Kept separate from reusable pipeline to avoid contamination
- **Instance database limitations acknowledged**: Multi-species instance approach has redundancy/false-positive concerns; consensus or multiz approaches recommended for expansion
