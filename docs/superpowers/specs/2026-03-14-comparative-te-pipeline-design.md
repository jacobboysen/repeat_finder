# Comparative TE Fossil Pipeline — dmel x dpse

**Date:** 2026-03-14
**Status:** Implemented
**Goal:** Run identical RepeatMasker-derived TE fossil pipelines on D. melanogaster and
D. pseudoobscura, then cross-BLAST each species' 3'UTRs against the other's TE database.
Produce four result sets + an ortholog lookup table for downstream comparative analysis.

## Motivation

The core question: **do orthologous gene 3'UTRs have similar TE fossil density across
Drosophila species?** By running both genomes through the same RM-based pipeline, we
control for methodology differences. Cross-BLAST reveals whether TE families in one
species leave detectable fossils in the other's UTRs.

D. pseudoobscura (~25 Mya divergence) is the comparison species. At this distance,
shared TE fossils in orthologous UTRs would be compellingly ancient and suggestive
of functional constraint.

14,343 protein-coding genes. Chromosomes use NCBI accession naming (NC_046679.1, etc.).

**3'UTR handling:** NCBI Gnomon GFF3 lacks explicit UTR features. 3'UTRs are inferred
from mRNA minus CDS coordinates by `infer_utrs()` in `fossil_finder.io.gff`. This
produces 25,726 inferred 3'UTRs (median 245 bp, mean 590 bp).

### D. melanogaster (existing)

Already in pipeline. Key change: **use RepeatMasker-derived TE consensus** instead of
FlyBase curated consensus, so both species get identical RM treatment. The existing
`dm6.fa.out` RepeatMasker output is already available.

## Pipeline Design

### Symmetric TE Library Construction

Both species follow the same path:

```
genome.fasta
  -> RepeatMasker (-species drosophila)
  -> .out file (repeat annotations)
  -> build_te_fasta_from_repeatmasker()
  -> TE consensus FASTA
  -> makeblastdb
  -> BLAST database
```

For dmel, we already have `dm6.fa.out`. For dpse, RepeatMasker runs as part of the
Snakemake workflow.

### Four BLAST Runs

| Run | Query (UTRs) | Subject (TE db) | Output dir |
|-----|-------------|-----------------|------------|
| 1 - dmel self | dmel 3'UTRs | dmel RM-derived TEs | `results/comparative/dm6/` |
| 2 - dpse self | dpse 3'UTRs | dpse RM-derived TEs | `results/comparative/UCI_Dpse_MV25/` |
| 3 - cross A | dmel 3'UTRs | dpse RM-derived TEs | `results/comparative/dm6_vs_UCI_Dpse_MV25_te/` |
| 4 - cross B | dpse 3'UTRs | dmel RM-derived TEs | `results/comparative/UCI_Dpse_MV25_vs_dm6_te/` |

### BLAST Parameters

```yaml
word_size: 7
gapopen: 2
gapextend: 1
penalty: -1
reward: 1
dust: false
evalue: 0.01
max_target_seqs: 10000
```

Changed from defaults: `evalue` raised from 0.001 to 0.01 (more permissive for
capturing diverged hits), `max_target_seqs` raised to 10000 to saturate each UTR.

## Snakemake Workflow Extension

### New rule: cross_blast

Uses `{query}` x `{subject}` wildcards. References the query genome's `regions.fa`
and the subject genome's BLAST database:

```python
rule cross_blast:
    input:
        query=lambda wc: str(OUTPUT_DIR / wc.query / "regions.fa"),
        db_nhr=lambda wc: str(OUTPUT_DIR / wc.subject / "blastdb" / "te_db.nhr"),
    output:
        tsv=str(OUTPUT_DIR / "{query}_vs_{subject}_te" / "blast_results.tsv"),
```

Cross-pairs are auto-generated for all loaded genomes: `CROSS_PAIRS = [(q,s) for q in GENOMES for s in GENOMES if q != s]`

### New feature: UTR inference

Added `infer_utrs()` to `fossil_finder.io.gff` — automatically infers 3'UTR and 5'UTR
features from mRNA/CDS coordinates when the GFF3 lacks explicit UTR annotations.
Triggered automatically in `parse_gff3()` when requested feature types include UTR types
but none are found in the file.
